## FAQ

### What exactly is XCutors?

XCutors is a curated collection that bundles several popular Windows Roblox executors like Volt and Synapse Z into a single package with a universal loader, simplifying access and management for users.

### Is this software safe to use?

The tools are designed for educational and personal customization purposes. As with any software that interacts with other programs, users should run it in a controlled environment and understand the potential risks, including temporary account restrictions.

### Which versions of Roblox are supported?

The executors are updated regularly to maintain compatibility with recent Roblox client updates. However, support may lag behind the very latest releases during initial testing phases after major Roblox patches.

### Do I need to run it with administrator privileges?

Yes, running the loader and loader with administrator rights is typically required for the tools to properly access system resources and attach to the Roblox game client process.

### What should I do if my anticomponent flags the software?

Some security software may flag injection tools due to their behavioral characteristics. You may need to add an exception for the XCutors folder in your anticomponent program after verifying the source's legitimacy.

### Can I use multiple executors at the same time?

The universal loader is designed to manage one active executor at a time. Switching between executors will require stopping the current injection and starting a new one for the selected executor.

### How do I load my own scripts?

After successfully injecting an executor, its built-in interface will provide options to open, paste, or execute Lua scripts from your local files or from a script hub if supported by that specific executor.

### Is there support for other operating systems like macOS?

No, this package, including all its bundled executors, is exclusively developed for and compatible with Windows operating systems only.
